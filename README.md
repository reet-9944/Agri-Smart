## 📌 Project Overview
**Agri-Smart** is an AI-powered advisory platform built for the **1M1B AI for Sustainability Virtual Internship**. It aims to help farmers accurately diagnose crop diseases, find cost-effective treatments, and share knowledge through a community feedback loop.

### 🌍 UN SDGs Addressed
- **SDG 2:** Zero Hunger
- **SDG 12:** Responsible Consumption and Production
- **SDG 15:** Life on Land

## 🚀 The Problem
Farmers frequently face crop diseases but struggle to accurately diagnose them. Misdiagnosis leads to the overuse of expensive, toxic pesticides, harming soil health, reducing profits, and damaging the environment. Furthermore, farmers lack a reliable platform to know which treatments are cost-effective or to share their real-world success stories.

## 💡 The AI Solution
When a farmer uploads a photo of a sick plant, Agri-Smart uses:
1. **Multimodal AI** to instantly diagnose the disease.
2. **RAG (Retrieval-Augmented Generation)** to search agricultural databases for eco-friendly treatments.
3. **Agentic AI** to recommend specific, cost-effective products available locally.
4. **Community Feedback Loop** to summarize reviews from other farmers who used the product, ensuring peer-reviewed reliability.

## 🛠️ Technologies Used (Conceptualized)
- IBM Granite Models
- Agentic AI Workflows
- Retrieval-Augmented Generation (RAG)
- Streamlit (For the UI Prototype)

## 💻 How to Run This Prototype Locally

1. Clone this repository:
```bash
git clone https://github.com/YOUR_USERNAME/AgriSmart.git
cd AgriSmart
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Run the Streamlit app:
```bash
streamlit run app.py
```
